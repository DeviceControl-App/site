# אתר DeviceControl

| קובץ | מה יש בו |
|---|---|
| `index.html` | האתר בעברית (דף הנחיתה + רשימת השגרירים) |
| `en.html` | האתר באנגלית |
| `assets/ambassadors-ui.js` | הקוד שמציג את רשימת השגרירים (לא צריך לגעת) |
| `ambassadors.js` | **רשימת השגרירים** – הקובץ היחיד שצריך לערוך |
| `assets/app-screen.jpg` | צילום המסך של האפליקציה |

## הוספת שגריר
פותחים את `ambassadors.js`, מעתיקים שורה ומשנים את הפרטים:

```js
{ name: "ישראל ישראלי", phone: "050-123-4567", city: "בני ברק", region: "מרכז" },
```

- `region` צריך להיות אחד מהאזורים ברשימה `REGIONS` שבראש הקובץ (אפשר להוסיף אזורים).
- `note: "..."` – הערה אופציונלית שתוצג בכרטיס.
- `active: false` – מסתיר שגריר בלי למחוק אותו.
- `name_en`, `city_en`, `note_en` – שם/עיר/הערה באנגלית לאתר האנגלי (לא חובה; אם חסר מוצג הטקסט העברי).

אותה רשימה משמשת את שני האתרים – עברית ואנגלית.

## שינוי טקסט באתר
טקסט שיווקי נמצא ישירות ב-`index.html` (עברית) וב-`en.html` (אנגלית). שינוי באחד צריך להיעשות גם בשני.

כדי לראות את האתר פותחים את `index.html` בדפדפן.
להעלאה לאוויר מעלים את כל התיקייה לאחסון סטטי כלשהו (Netlify, GitHub Pages, Cloudflare Pages וכו').

## התקנה עצמאית ומחירי התקנה
באתר יש מקטע "שתי דרכים להתקין" (`#install`) שמופיע לפני רשימת השגרירים:
- **התקנה עצמאית – חינם**: קישור לאשף ההתקנה https://devicecontrol.dctech.co.il/installer/ (דפדפן Chrome במחשב או בטלפון נוסף + כבל USB; צריך ניפוי באגים ב-USB והסרה זמנית של כל החשבונות במכשיר)
- **התקנה אצל שגריר – ₪40 חד-פעמי** (על ההתקנה בלבד; הרישיון המלא בנפרד).

כדי לשנות מחיר או קישור – לערוך את המקטע `<!-- INSTALL OPTIONS -->` ב-`index.html` וב-`en.html`.
